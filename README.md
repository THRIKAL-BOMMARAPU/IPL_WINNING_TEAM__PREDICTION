
## 🏏 IPL WINNING TEAM PREDICTION

## 📌 Project Overview
The **IPL Victory Probability Estimator** is a data-driven machine learning project that predicts the outcome probabilities of Indian Premier League (IPL) matches. Designed for cricket enthusiasts, analysts, and developers, this tool provides real-time predictions based on live or hypothetical match conditions.

---

## 🎯 Objective

The primary objectives of this project are to:

- Develop a predictive model using historical IPL match data.
- Provide accurate probability estimates for match outcomes.
- Enhance the viewing and analytical experience for IPL fans.

## ⚙️ How It Works

- **Data Loading:** The IPL dataset is sourced from Kaggle and processed using pandas.
- **Feature Engineering:** Extracts relevant features like current score, overs, wickets, and required runs.
- **Model Training:** A machine learning model is trained to predict winning probabilities.
- **Model Saving:** The trained model is saved using `pickle` for deployment.
- **Web Application:** A user-friendly interface is built using Streamlit where users can:
  - Input live or custom match details
  - Get instant predictions of win probabilities for each team

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/IPL-Victory-Probability-Estimator.git
cd IPL-Victory-Probability-Estimator
````

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the Streamlit app

```bash
streamlit run app.py
```

---

## 🔮 Sample Prediction Interface

Once the app is running, users can input match details such as:

* Batting and bowling team
* Current score
* Overs completed
* Wickets lost
* Target score

The app will display the **winning probability** for each team based on the input.
